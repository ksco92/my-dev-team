# my-dev-team

Claude Code plugin: TPM orchestration, tiered implementers, five review gates, and stack guides, with the tracker, code host, and workspace choices read from a DEV_PROCESS.md file.

## Installation

From this marketplace:

```
claude plugin marketplace add ksco92/my-dev-team
claude plugin install dev-team@ksco92
```

Or from a local clone, kept current with `git pull`:

```
claude plugin marketplace add /path/to/clone
```

The plugin is a skeleton today; content lands in later versions.
